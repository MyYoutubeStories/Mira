# Район Каннам — 13 лет назад

## Файлы

- `index.html` — страница сайта
- `style.css` — оформление
- `photo.jpg` — главное фото

## Как добавить своё фото

Положи изображение в эту же папку и назови его `photo.jpg`.

Если у тебя PNG, можешь назвать его `photo.png` и заменить `photo.jpg` в `style.css` на `photo.png`.

## GitHub Pages

1. Создай новый репозиторий на GitHub.
2. Загрузи `index.html`, `style.css` и `photo.jpg`.
3. Открой Settings → Pages.
4. В разделе Build and deployment выбери `Deploy from a branch`.
5. Выбери ветку `main` и папку `/ (root)`.
6. Нажми Save.
7. Через некоторое время GitHub покажет адрес опубликованного сайта.
